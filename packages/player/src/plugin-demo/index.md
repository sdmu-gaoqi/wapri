# 插件演示

一个视频，上面一排按钮把插件挨个切给你看。默认插件只有画面调节与网页全屏，其余按钮会在默认之上临时追加对应插件。

<code src="./demo/scenes.vue"></code>

## 按钮说明

| 按钮 | 用到的插件 | 做了什么 |
| --- | --- | --- |
| 全部默认 | `filter`、`webFullscreen` | 就是组件默认的两个插件，与不传 `plugins` 一致 |
| 画面调节 | `filter` | 把亮度 140、对比度 120、饱和度 150 作为初始值 |
| 马赛克 | `mosaic` | 追加插件并打开开关，块大小 24 |
| 模糊 | `blur` | 追加插件并打开开关，模糊半径 8 |
| 绿幕 | `chromaKey` | 追加插件并打开开关，相似度 0.45 |
| 视频滤镜 | `videoFilter` | 追加插件，预设「复古」、强度 80% |
| 截图 | `screenshot` | 调实例方法 `screenshot()` 下载当前帧 |
| 网页全屏 | `webFullscreen` | 切换 `art.fullscreenWeb`，再点一次退出 |

## 注意

- 切场景会重建播放器实例，播放进度与播放状态会自动接上；全屏、画中画状态不保留。
- 绿幕是逐像素抠像，示例视频里没有纯绿背景，看到的是「相近色被抠掉」的效果，换成绿幕素材才准确。
- 每个场景只让一个效果生效，方便看清单个插件的作用。
