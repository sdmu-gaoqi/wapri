# 插件演示

一个视频，上面一排按钮把默认插件的效果挨个切给你看。默认插件一共六项：画面调节、马赛克、模糊、绿幕、截图、网页全屏。

<code src="./demo/scenes.vue"></code>

## 按钮说明

| 按钮 | 对应的默认插件 | 做了什么 |
| --- | --- | --- |
| 全部默认 | - | 就是组件默认的六个插件，与不传 `plugins` 一致 |
| 画面调节 | `filter` | 把亮度 140、对比度 120、饱和度 150 作为初始值 |
| 马赛克 | `mosaic` | 打开开关，块大小 24 |
| 模糊 | `blur` | 打开开关，模糊半径 8 |
| 绿幕 | `chromaKey` | 打开开关，相似度 0.45 |
| 视频滤镜 | `videoFilter` | 额外装上滤镜插件，预设「复古」、强度 80% |
| 截图 | `screenshot` | 调实例方法 `screenshot()`，直接下载当前帧 |
| 网页全屏 | `webFullscreen` | 切换 `art.fullscreenWeb`，再点一次退出 |

## 注意

- 切场景会重建播放器实例，播放进度与播放状态会自动接上；全屏、画中画状态不保留。
- 绿幕是逐像素抠像，示例视频里没有纯绿背景，看到的是「相近色被抠掉」的效果，换成绿幕素材才准确。
- 画面调节、马赛克、模糊、绿幕同时只会生效一个，因为每次切换都重置了插件配置。
