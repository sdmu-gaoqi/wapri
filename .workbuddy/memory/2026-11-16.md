## 文档页报错：md 里的 ```vue 代码块会被当 SFC 编译

- 现象：dumi 打开 `/players/default-plugins` 报 `At least one <template> or <script> is required in a single file component`，文件名指向 md。
- 原因：`@dumijs/preset-vue` 的 sfc techStack 会把 md 中 ` ```vue ` 代码块交给 `compileSFC`，裸模板片段（如只有 `<VideoPlayer ... />`）没有 template/script 就抛错。
- 约定：纯模板片段一律用 ` ```html `，只有完整的 `<template>` + `<script setup>` 才用 ` ```vue `（这类块会被渲染成可运行 demo）。
- 自查脚本：用 `@vue/compiler-sfc` 的 `parse` 扫 `packages/**/*.md` 里的 ```vue 块，检查 `descriptor.template/script/scriptSetup` 是否存在；当前 96 个 md 全部通过。
- 环境限制：`npx dumi dev` 也会被 safe-delete shim 拦截（要清理 `.dumi/tmp` 下 50 个文件），本地验证 doc 只能在用户终端跑。
