## utils 新增火山云 TOS 图片处理

- `@base` 新增 `src/image.ts`、`src/constant/image.ts`、`src/types/image.ts`，`src/index.ts` 已导出实现 / 常量 / 类型；utils 通过 `export * from '@wapri/gbase'` 自动透出，无额外代码。
- 导出：`withTosImageProcess(url, options)`、`buildTosImageProcess(options)`、`getTosImageProcess(url)`、`removeTosImageProcess(url)`；类型 `TosImageProcessOptions` / `TosImageFormat` / `TosImageResizeMode` / `TosImageQualityType`；常量 `TOS_IMAGE_PROCESS_KEY`、`TOS_IMAGE_PROCESS_PREFIX`、`TOS_IMAGE_MAX_SIZE`、`TOS_IMAGE_QUALITY_RANGE`。
- 处理串格式：`?x-tos-process=image/resize,w_300/quality,Q_70/format,webp`，顺序固定为 auto-orient → resize → quality → format。
- 要点：`qualityType` 默认 `absolute`（`Q`，jpg/webp 都生效）；`q` 只对 jpg 生效。`resize` 的 `limit` 默认为 1（不放大），单边宽高由服务端按比例推算，`fill`/`pad` 会构造正方形框。`width/height` 优先于 `longEdge/shortEdge`。
- 文档：`packages/utils/src/image/index.md`；changeset `.changeset/tos-image-process.md`（gbase / gutils minor）。
- 验证：tsc 无 image 相关错误、oxlint 0 error、oxfmt 通过；22 条用例全通过；真实 TOS 示例图（`tos-tools` 公共域名，非业务域名）返回 200 + `image/webp`，71550B → 2926B。

## 新增 player 包（@wapri/gplayer）

- 包位置 `packages/player`，包名 `@wapri/gplayer`，构建走 vite lib（对齐 element-pro，需要编译 SFC），external：`vue` / `artplayer` / `@wapri/gbase`。
- 组件 `VideoPlayer`：`url` + 常用属性 + `options` 透传 artplayer，`defineExpose` 暴露 `player`/`play`/`pause`/`toggle`/`seek`/`screenshot`/`fullscreen`。
- 插件协议：`plugins: Array<string | { key; setting }>`；`setting(默认配置) => Partial<配置>`，同 key 去重后出现覆盖，未知 key 警告跳过；读类型化配置用 `pluginEntry('key', fn)`。注册表在 `src/core/registry.ts`，模块初始化时用 `builtinPlugins` 播种（包是 sideEffects:false，不能靠副作用导入）。
- 内置 7 个插件（各占右侧菜单一项）：`playbackRate`、`aspectRatio`、`flip`、`screenshot`（canvas 重绘 + downloadBlob，需 CORS）、`pip`、`abLoop`、`filter`（写 `video.style.filter`）。
- artplayer 5.4 关键事实：`option.plugins` 只接受函数数组；`art.setting.add()` 运行时返回菜单项（类型声明写成了 setting 组件，需断言）；菜单回调返回值会写回右侧副标题（`onSelect`/`onChange`/`onClick` 返回新副标题，`onSwitch` 返回新开关态）；默认所有附加按钮都是 false，`setting` 需手动开。
- 文档：`/players` 按「简介 / 每个插件一页 / 自定义插件 / API」拆开，每页自己的 `demo/basic.vue`；截图页换成带 CORS 的 jsDelivr 视频源。
- 测试：`packages/player/tests/plugin.test.mjs`（`node --test`，vite 构建 TS 入口 + mock art），13 条覆盖配置解析与插件行为。
- 验证：`pnpm build` 7/7、`pnpm doc` 318 文件、`pnpm lint` 0 error（11 条历史 warning 全来自 gbase）、openspec validate 通过。
