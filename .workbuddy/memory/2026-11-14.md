- 导出：`withTosImageProcess(url, options)`、`buildTosImageProcess(options)`、`getTosImageProcess(url)`、`removeTosImageProcess(url)`；类型 `TosImageProcessOptions` / `TosImageFormat` / `TosImageResizeMode` / `TosImageQualityType`；常量 `TOS_IMAGE_PROCESS_KEY`、`TOS_IMAGE_PROCESS_PREFIX`、`TOS_IMAGE_MAX_SIZE`、`TOS_IMAGE_QUALITY_RANGE`。

## player 新增帧渲染管线与 11 个内置插件

- 新增 11 个插件：`webFullscreen`、`videoFilter`、`mosaic`、`blur`、`backgroundBlur`、`stabilizer`、`chromaKey`、`vertical`、`reverse`、`intro`、`overlay`，内置插件从 7 个到 18 个。
- 默认插件：`defaultPlayerPlugins`（`src/constant/index.ts`）= `['filter','screenshot','webFullscreen','mosaic','blur','chromaKey']`，element-pro 的 `fileListVideoPlugins` 同步到 `'playbackRate','aspectRatio','filter','flip','pip'` + 这 5 个。后三个效果插件默认 `enabled: false`，只是菜单可见。
- 帧渲染核心 `core/frame.ts`：`PluginContext.frame` 是懒创建的共享 canvas 渲染器，`set(key, params | null)` 写入效果；工作画布长边 1280（绿幕 960），顺序 绿幕 → 马赛克 → 模糊/视频滤镜/画面调节（合成 ctx.filter）→ 背景模糊 → 防抖（帧间混合）→ 输出。无 effect 不建 canvas、不跑 rAF。
- `frame.set` 传 `null` 也会创建渲染器对象但不会建 canvas（`stop()` 里 `if (overlay)` 兜底），所以默认启用三个效果插件没有额外开销。
- `core/cssFilter.ts`：按 key 管理 filter 片段，`filter` 与 `videoFilter` 都走它，`video.style.filter` 不再互相覆盖；`frame` 每帧读 `video.style.filter` 内联值作为基础滤镜，所以 canvas 覆盖后滤镜仍然生效。
- 适配方式 `FrameFit = 'contain' | 'cover' | 'fill'`：artplayer 的 `.art-video` 是 `object-fit: fill`，默认必须用 `fill` 才不变形；开了 `backgroundBlur` 前景切 `contain`，开了 `vertical` 用插件给的 fit。
- 层级：canvas `z-index: 20`（video 10 / layers 40 / bottom 60），intro 40，overlay 30；覆盖层样式由 `core/style.ts` 注入一次。
- 限制：倒放靠 rAF 回退 `currentTime`（浏览器不支持负 playbackRate），防抖是帧间混合不是物理稳像，截图仍只输出原始帧 + filter，不含 canvas 效果。
